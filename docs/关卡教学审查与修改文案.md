# 关卡与教学审查 · 修改文案（待审）

> 审查对象：麦田小课堂 v1.0.0（44 关 / 8 章）
> 审查重点：关卡与教学的对应关系是否成立、引导流程是否顺畅、是否够儿童友好
> 审查方式：逐关比对 `src/core/levels.js` 的目标 / 提示 / 初始代码 / 参考解，结合 `src/ui/app.js`
> 的引导交互与 `tests/levels.test.mjs` 的校验口径
> 本文是审查报告 + 修改文案；文末「落地记录」汇总已经改掉的部分和暂缓的部分

---

## 一、结论先说

项目底子很扎实：一关只教一个新概念、参考解能过且能拿三星、本章没学的指令会被拦截并引导到对应章节。
真正的短板集中在三个地方：

1. **有 5 处文案与事实不符**（最典型：模式入口写「32 关」，实际是 44 关），会直接误导孩子；
2. **概念覆盖有缺口**：`后退 N`、`买鸡`、`买牛` 从头到尾没有正式教过，但后面关卡 / 指令口袋会用到；
3. **面向儿童的"前置引导"几乎是空的**：没有章前小课堂、没有第一关手把手、提示默认收起、参考答案一键就给，
   孩子遇到卡点时只能自己读大段文字——这对儿童向产品是不够的。

## 三、逐项问题与依据

### P0-1　「32 关」是硬伤

现状：

- `src/ui/app.js:184`：教学模式卡片脚注 = `32 关 · 顺序 / 重复 / 判断 / 牧场`
- `src/ui/app.js:405`：全部通关时 = `32 关已全部完成 · 已获得 ${stars} 颗星`

事实：课程是 **44 关 8 章**（`src/core/levels.js:2`，`tests/levels.test.mjs` 也断言 44）。

顺带：教学模式脚注只列了 4 章，漏了「综合 / 经营 / 集市 / 自动农活」。

### P0-2　数格提示差一格

- 第 1 关提示 2（`levels.js:133`）："数一数他和旗子之间隔了几格，就写几行。"
  - 地图是 `@G`，中间"隔了 0 格"，但答案是 `前进 1`。
- 第 3 关提示 2（`levels.js:167`）："步数就是他和旗子之间隔的格数。"
  - 地图上下相距 3 格（`@ → . → . → G`），"隔了 2 格"，但答案是 `前进 3`。

对儿童来说，"隔几格"和"走几步"是两回事，这里必须统一成 **"从脚下开始，走一步数 1"**。

### P0-3　第 13 关没有"小屋"

`levels.js:325` 副标题 = `绕着小屋走一圈`，但该关地图是纯空地：
`field(['@.....','......','......','......','G.....'], 8)`，没有任何 `H`（小屋）或建筑。
建议改成"沿着田边走到旗子"之类与画面一致的描述，或干脆给地图加一间小屋。

### P1-4　`后退 N` 教学缺口

- 第 5 关只教单步 `后退`（`newCommands: ['后退']`）。
- 但从第 28 关起参考解就出现 `后退 1 / 后退 3 / 后退 4 / 后退 6`。
- 孩子在指令口袋里看到的是「后退 N」，却从没被正式教过可以写数字。
- 建议：第 5 关直接教 `后退 N`（一关一个概念的口径仍然成立，因为"后退带步数"就是一个概念），
  或拆成"第 5 关 后退一格 / 第 6 关 后退 N"两关（后面所有关卡顺延）。

### P1-5　`买鸡` / `买牛` 没进教学

`PALETTE` 里第 7 章解锁「买鸡」「买牛」，`MARKET_COMMANDS` 也把它们算作集市指令，
但 37~44 关没有一关的目标用得到它们，孩子从没学过。
建议二选一：

- 方案 A：把「买鸡 / 买牛」从教学模式的指令口袋移到**自由模式专属**；
- 方案 B：第 7 章补一关"扩大农场"（例如买 1 只鸡、喂饱、等一天、收蛋）。

### P1-6　缺"章前小课堂"

现在换章节只是 `loadLevel()` 换一关，没有任何过渡。8 个章节各引入一个大概念
（顺序 / 重复 / 判断 / 牧场 / 综合 / 经营 / 集市 / 自动农活），全靠任务卡一句话。
对儿童，**每个新概念都需要一张"穗穗小课堂"卡片**：一句话说明 + 一个最小例子 + "知道了，开始"。
本文第五节给了 8 段可直接用的文案。

### P1-7　第 1 关缺手把手

- 第 1 关 `starter` 已经写好 `前进`，但 `objective` 仍是"写一行「前进」"——**说的和看到的对不上**。
- 页面里没有任何地方告诉孩子"点 ▶ 运行"（全项目只有配音文案里提过一次"再点运行"）。
- 建议第 1 关改成：高亮「▶ 运行」+ 气泡引导 + 第一次运行后的解释。文案见第四节 A。

### P1-8　「看答案」太容易

`answerBtn` 从第 1 关起就可见，点一下直接 `editor.setValue(level().solution)`。
建议：

- 第一次点击弹确认框："真的要看答案吗？自己试一次，会记得更牢哦。"
- 或：前 2 次运行失败后才显示「看答案」，之前按钮置灰并提示"先自己试一次"。

### P1-9　提示默认收起、失败不自动展开

`hintDrawer` 默认 `hidden`，只有主动点「提示」才展开；运行失败只在气泡里给一句话。
建议：**失败一次后自动展开提示抽屉**，并在气泡里给"下一步做什么"的一句话。

### P2-10　提示层次不清（有的直接是答案）

- 第 29 关提示 3 = "这段要写成：重复 6 次 { 前进 / 如果 脚下是草地 { 翻土 } / 播种 }"
- 第 31 关提示 2 = "重复 9 次：前进，然后判断「如果 奶牛可以挤奶」，有奶才挤。"
- 第 36 关提示 1/2/3 基本拼出完整解

建议统一成三层（本文第四节给模板）：第 1 条讲概念、第 2 条给方向、第 3 条给"句式骨架"（不给完整数字/路线）。

### P2-11　配音只读第一条提示

`tutor-lines.js` 的 `levelLine()` 只取 `def.hints[0]`。
建议孩子点开每一条提示时都能听（或至少提供"读给我听"按钮），并给"新概念卡片"配一段音。

### P2-12　指令口袋缺说明

`renderPalette()` 只输出按钮名，`title` 仅写"点击插入到代码里"。
建议每个按钮补一句 `title` / 长按说明，例如"前进 N：往前走 N 格"。

### P2-13　自由模式门槛

建议教学模式卡片加"推荐先玩"，自由模式卡片加一行小字
"建议先玩完第 1 章，再来自由农场更轻松"。

### P2-14　用语儿童化

| 位置 | 现状 | 建议 |
| --- | --- | --- |
| 第 5 关副标题 | 不倒车也能退 | 往后退，不用转身 |
| 第 31 关关名 | 牛棚巡检 | 只挤有奶的牛 |
| 第 36 关关名 | 大农场收官 | 大农场的一天 |
| 第 44 关关名 | 自动农活收官 | 自动农活毕业 |

### P2-15 / P2-16　第 37、38 关文案

- 37 关提示 1 承诺"集市价目表就在关卡提示里"——建议真的加一张价目表，或改成
  "价格是：鸡蛋 3 金币、牛奶 5 金币、小麦 2 金币。"
- 38 关"集市旁边有 12 金币"——金币是玩家的，建议改成"你现在有 12 金币"。

### P3-17　HUD 资源歧义

`free` 模式里 `🐔 鸡 2/3` 表示"饿着 2 / 共 3"。建议改成
`🐔 没喂 2/3`、`🐄 没喂 2/3`，或加"饱/饿"图标区分。

### P3-18　章节完成缺庆祝

`showWinModal()` 只有"下一关"，章节最后一关和普通关没有区别。
建议章节最后一关弹"🎉 第 N 章 · XX 全部完成！下一章学……"，文案见第四节 F。

## 五、建议的引导流程（交互层面）

面向儿童，"看得见的下一步"比大段文字更重要。建议把每关的引导固定成下面这套节奏：

1. **进关 → 章前卡片**：只有换章节 / 出现新概念时才弹「穗穗小课堂」，自动读一遍。
2. **进关 → 任务卡 + 气泡**：气泡只说一句"这一步要做什么"。
3. **首次进入第 1 关 → 高亮「▶ 运行」**：按钮做呼吸高亮 + 小手指提示。
4. **运行失败 → 自动展开提示 + 标红行 + 一句"下一步"**：不要让孩子自己去找「提示」。
5. **连续失败 2 次 → 才显示「看答案」**：避免刚上手就抄答案。
6. **过关 → 先夸再报数**：先说"太棒了"，再说步数和星星；章节末追加章节完成卡。
7. **自由模式 → 首次进入给 3 步穗穗引导**：先种一格小麦 → 收稻草 → 喂鸡。

配套建议：

- 每条指令在"指令口袋"里配一句说明和一个小例子（`title` / 长按气泡）。
- 任务卡与提示尽量用短句 + 图标，长句拆成两行，关键指令用彩色标签。
- 新概念卡片和所有提示都要有配音（目前只有第 1 条提示配了音）。

## 六、落地清单与注意事项

**改文案后必须同步的**

1. `hints[0]` 一旦改动，`TUTOR_LINES` 的指纹会变，`npm test` 会报"配音没重新生成"。
   需要跑：`node tools/generate_tutor_voice.mjs --only=level-1,level-2,...` 再跑 `npm test`。
2. 第 1 关 `starter` 保持"已写好一行示范"的口径时，`tests/levels.test.mjs` 里
   "初始代码不是完整答案"对第 1 关是放行的，不用改。
3. 若采纳"第 5 关补教 `后退 N`"，需同步：`newCommands`、`PALETTE`、参考解步数（`par`）、配音。
4. 若"买鸡 / 买牛"从教学模式指令口袋移除，需同步 `PALETTE` 与 `MARKET_COMMANDS`（仅影响拦截提示）。
