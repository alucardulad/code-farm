## 1. 背景与目标

### 1.1 现状盘点（改造前）

| 模块 | 现状 | 问题 |
| --- | --- | --- |
| 种地闭环 | 翻土→播种→浇水→等待一天→成熟→收获，产出小麦/种子/稻草 | 已经很完整，保持 |
| 养鸡闭环 | 收获得稻草 → 鸡舍旁「喂鸡」→ 等一天 → 鸡舍有蛋 → 「收鸡蛋」 | 基本完整，缺状态展示 |
| 牧牛闭环 | 牛旁边直接「挤奶」，每天一瓶 | **缺"喂牛"，牛不会饿，没有照顾过程** |
| 第 4 章（23~28） | 喂鸡、收蛋、挤奶三个指令 | 牧牛只有一半，没有综合经营感 |
| 第 5 章（29~32） | 基本只种地 | 养鸡、牧牛没进最终综合 |
| 自由模式 | 能种地/喂鸡/挤奶，资源计数 | 缺"每日农活清单"，经营感弱 |
| 条件判断 | 只有 4 个脚下地形条件 | 无法判断动物状态（有没有蛋、能不能挤奶） |

### 1.2 本次目标

1. **补全牧牛闭环**：新增 `喂牛` 指令，牛需要吃稻草，吃饱后第二天才产奶。
2. **强化养鸡闭环**：鸡/牛都有可见状态（饿 / 吃饱 / 有蛋 / 可挤奶 / 已挤过）。
3. **动物进入代码教学**：新增动物状态条件判断，让「如果」能用在牧场上。
4. **改造第 4、5 章**：第 4 章变成真正的「牧场经营章」，第 5 章毕业关是完整农牧一天。
5. **强化自由模式**：每日农活清单 + 经营记录，让经营感落地。
6. **全程不破坏现有风格**：中文指令、一关一个新概念、穗穗提示、关卡参考解必须能过且三星。

### 1.3 硬性约束（不可违背）

- **参考解必须能通关并且拿到三星**（测试会真跑一遍）。
- **本章没教的东西要被教学拦截**，给提示而不是报错。

## 2. 农牧闭环设计

### 2.1 时间系统（唯一时间轴）

「等待一天」一次性处理所有事情，把三条链路串到同一天里：

1. 浇过水的幼苗 → 成熟小麦；
2. **喂饱的鸡** → 鸡舍里下蛋（攒着等收）；
3. **喂饱的牛** → 第二天产奶（可以挤）；
4. 所有动物进入新的一天（饱食状态清零）。

### 2.2 种地闭环（保持）

```
翻土 → 播种 → 浇水 → 等待一天 → 成熟小麦 → 收获
收获产出：+1 小麦 / +5 金币 / +2 种子 / +1 稻草
```

### 2.3 养鸡闭环

```
收获小麦得稻草 → 走到鸡舍旁 → 喂鸡（1 鸡 1 天 1 捆稻草）
→ 等待一天 → 鸡舍出现鸡蛋 → 走到鸡舍旁 → 收鸡蛋
```

鸡的状态：`饿了`（有鸡没喂）/ `吃饱了`（今天喂过，等一天下蛋）。

### 2.4 牧牛闭环（本次新增）

```
收获小麦得稻草 → 走到奶牛旁 → 喂牛（1 牛 1 天 1 捆稻草）
→ 等待一天 → 奶牛产奶 → 走到奶牛旁 → 挤奶（1 牛 1 天 1 瓶）
```

奶牛的状态：

| 状态 | 含义 | 画面表现 |
| --- | --- | --- |
| 饿了 | 今天没喂，明天不会产奶 | 头顶「稻草」气泡 |
| 吃饱了 | 今天喂过，等一天产奶 | 头顶「✓」气泡 |
| 可以挤奶 | `milkReady === true` | 头顶奶滴（已有） |
| 今天挤过了 | `milkReady === false` | 不显示奶滴 |

### 2.5 动物状态条件判断（本次新增）

复用现有 `如果` 语法，不新增复杂语法：

```
如果 奶牛可以挤奶 { 挤奶 }
如果 鸡舍里有鸡蛋 { 收鸡蛋 }
```

# 第四阶段：条件循环「重复直到」（T17~T20）

> 前三阶段教了顺序、重复、判断、两选一，循环次数都是**事先数好**的。
> 第四阶段补上最后一块控制结构：**一边做一边看条件，条件不成立就一直做**
> —— 也就是编程里的 while 循环。农活里到处都是这种场景：
> 「一直往前走，直到看见熟麦」「一直等，直到鸡下蛋」。

## 17. 本阶段目标

1. 新增中文语法 **`重复直到 条件 { ... }`**：条件不成立就重复做，成立就停。
2. 新增两个配套条件：**`前方是成熟小麦`**、**`到旗子了`**（实现时改用正向写法，见「与计划的两处偏差」）。
3. 新增 **第 8 章 · 自动农活（41~44 关）**，关卡总数 40 → **44**。
4. **自由模式扩充**：金币可以**买鸡买牛**扩栏，让钱有第二个去处。
5. 循环次数不再靠数，改由条件决定 —— 但必须有**防死循环保护**和**人话提示**。

### 与前面章节的关系

| 章节 | 循环方式 | 次数怎么定 |
| --- | --- | --- |
| 第 2 章 · 重复 | `重复 N 次 { }` | 事先数好 |
| 第 8 章 · 自动农活 | `重复直到 条件 { }` | 由条件决定，不用数 |

### 与计划的两处偏差（已确认更合适，保留）

1. **条件用正向写法 `到旗子了`，没用计划里的 `还没到旗子`。**
   双重否定（「还没到旗子」不成立）对小朋友太绕；改成「重复直到 到旗子了 { 前进 }」，
   句意和中文口语一致，读起来就是「一直走，到旗子就停」。
2. **补充修掉一个漏配：第 5、6 章的 `forbidden` 少了 `until`。**
   计划 T18 写的是「第 1~7 章都加 `until`」，实现时第 5、6 章漏了，
   导致第 29~36 关能偷用「重复直到」。已给 `ch5`/`ch6` 补上 `until`，
   并新增测试「第 1~7 章每一章都拦得住「重复直到」」按章节逐个把关。

- `重复直到` 目前只支持单条循环，没有 `break` / `continue` 之类的跳出写法，符合「一关一个新概念」的节奏。
- 自由模式的动物数量只有地图空地兜底，没有硬上限；以后想限制规模就在 `findAnimalSpot` 里加条件。
