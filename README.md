# 🌾 麦田小课堂

**用中文写代码，教小农夫种地。** 一个把「中文代码指令」和「像素农场养成」揉在一起的编程入门小游戏。

孩子在左边写下中文代码，小农夫就在右边的农田里照着做：翻土、播种、浇水、收获，
再去喂鸡、喂牛、收鸡蛋、挤牛奶，最后拉到集市把收成换成金币、买回种子接着种下一轮。
**8 章 44 关**打下来，顺序、重复、判断、两选一、条件循环五大编程基础，
就跟着一锄头一锄头长进手里了。

## 📖 教学是怎么设计的（以「第 1 章 · 顺序」为例）

### 这一章只教一件事

> **把想做的事按顺序写成一行一行，让指令一步一步执行。**

正式开始前，丰收仙女穗穗会先上一张**「穗穗小课堂」卡片**：一句话讲清概念，配一个最小例子，
还能点开来听。第 1 章这张卡片上写的就是：

```text
什么是「顺序」？
小农夫做事一步接一步：先写哪一行，就先做哪行。写错了不要紧，改一改再运行就好。
例子：前进 → 他往前走一格
```

### 10 关，就是 10 个小台阶

第 1 章 10 关，每关只加一个新东西，前 9 关学的都会成为下一关的地基：

| 关 | 这一关新教的 | 参考解 |
| --- | --- | --- |
| 1 · 向前一步 | `前进` | `前进` |
| 2 · 走远一点 | 给指令写步数 | `前进 9` |
| 3 · 向右转 | `右转` | `右转` → `前进 3` |
| 4 · 向左转 | `左转`（和右转相反） | `左转` `前进 3` `右转` `前进 5` |
| 5 · 后退 | `后退 2`，不用转身 | `后退 2` |
| 6 · 翻土 | `翻土` | `翻土` |
| 7 · 播种 | `播种`（只能撒在翻好的土上） | `翻土` `播种` |
| 8 · 浇水 | `浇水` | `翻土` `播种` `浇水` |
| 9 · 等待一天 | `等待一天`，幼苗睡一晚长大 | `翻土` `播种` `浇水` `等待一天` |
| 10 · 收获 | `收获`，拿金币也拿回种子 | 上面 4 步 + `收获` |

看第 10 关的参考解就知道设计意图：它把前面 4 关学的动作串成一条完整的农活链，
孩子不用学任何新语法，只要把学过的按顺序排好——**这一章的主旨「顺序」就自然长出来了**。

三条不打折扣的规矩：

- **一关只教一个新东西**：新指令不会提前出现在初始代码里，也不会提前出现在指令口袋里。
- **初始代码不是答案**：只留一行示范（第 1 关就是一整行 `前进`），剩下的必须自己写。
- **每关参考解都会被自动测试真跑一遍**，过不了关或者拿不到三星，测试直接失败。

### 孩子在一关里会经历什么

以第 8 关为例：

1. **任务卡**在右边写着：「种子不会自己长大。翻土、播种，再给幼苗浇点水。」
2. 左下角**指令口袋**里排着这一章学过的指令，每个按钮都带一句说明，点一下就插进代码框。
3. 孩子自己拼出三步：

   ```text
   翻土
   播种
   浇水
   ```

4. 点 **▶ 运行**。小农夫一行一行执行，**正在跑的那一行会亮起来**。第 1 关时这个按钮还会自己闪一闪，
   告诉孩子从哪儿开始。
5. **写错了不炸**：出错那一行标红，**提示自动摊开**，穗穗念一条语音，气泡里再补一句「下一步做什么」，
   例如：「别急，这块地还没翻过，先用「翻土」吧　左边的「穗穗提示」已经打开，对照着改一行再运行。」
6. **过关按行动次数评三星**：刚好用参考解的步数是三星，多几步两星，再多一星。
   结算卡会报「用了 3 步动作（三星线 3 步）」，也会顺手报农场现在有多少金币和收成。
7. 每章**最后一关**的结算卡会变成「🎉 第 X 章 全部完成！」，先夸一整个章节，再预告下一章学什么。

### 没学过的语法，会被「拦住」而不是报错

孩子在第一章里偷写「重复」，看到的不是 SyntaxError，而是一句人话：

> 这一章还用不了「重复」，先把每一步写成一行

每一类新语法都有对应的拦截和指引：前 3 章偷用「喂鸡 / 喂牛 / 收鸡蛋 / 挤奶」会被引到第 4 章牧场，
前 5 章偷用「否则」引到第 6 章经营，前 6 章偷用「卖出 / 买种子 / 买稻草」引到第 7 章集市，
前 7 章偷用「重复直到」引到第 8 章自动农活。条件循环还会额外防死循环：单条最多跑 100 遍，
条件写反了会被拦下并给提示，不会把浏览器转死。

### 卡住的时候，工具是「扶着走」而不是「直接给答案」

- **提示抽屉**里每条提示左边都有一个 🔊，识字不多的孩子可以一条一条听；
  第一条是穗穗把这一关整体讲一遍，后面几条才是具体做法。
- **「看答案」有门槛**：同一关失败两次才解锁按钮，点之前还要再确认一次，
  拿到的参考答案也会先劝一句「先看懂每一步为什么这样写，再清空自己写一遍」。
- 每次失败都会自动摊开提示，孩子不用自己想到「我该去点提示」。

## 🏪 自由市场：农场怎么转起来

### 为什么非要有个集市

种地要种子，养鸡养牛要稻草——**光靠自己收获，农场迟早会卡住**。集市把最后一环补上：

```text
鸡蛋 / 牛奶 / 小麦  ──「卖出」──▶  金币  ──「买种子 / 买稻草」──▶  接着种、接着养
```

### 自由农场长这样

![自由市场](preview/09-自由市场.png)

> 自由模式一开局就是这片农场：3 只鸡、3 头奶牛，左下角那栋 2×2 的木棚就是集市。
> 顶栏一直摆着家底——金币、小麦、稻草、鸡蛋、牛奶、鸡舍里攒着的蛋，
> 还有「没喂鸡 3/3」「没喂牛 3/3」「可挤 1」「可卖 1」这种一眼能看懂的状态。

### 价目表

| 生意 | 价格 |
| --- | --- |
| 卖出 🥚 鸡蛋 | 3 金币 / 枚 |
| 卖出 🥛 牛奶 | 5 金币 / 瓶 |
| 卖出 🌾 小麦 | 2 金币 / 袋 |
| 买 🌱 种子 | 3 金币 → 2 颗 |
| 买 🧺 稻草 | 4 金币 → 1 捆 |
| 买 🐔 鸡 | 12 金币 → 1 只（自由农场专用） |
| 买 🐄 牛 | 20 金币 → 1 头（自由农场专用） |

### 「卖出」是清空背包的一条指令

集市在地图上占 2×2 格，**走不过去，只能绕**。人得站到集市上下左右的相邻格，写一行「卖出」，
背包里的鸡蛋、牛奶、小麦会**一次性全卖掉**，金币一次到账。几种常见反馈都很直白：

- 站得太远：「走到集市旁边再卖东西吧」
- 背包是空的：「背包里没有可以卖的东西，先去收鸡蛋、挤牛奶或收小麦」
- 钱不够买东西：「金币不够，买稻草要 4 金币，还差 2」

### 第 7 章用 4 关把买卖教完

| 关 | 学到什么 |
| --- | --- |
| 37 · 集市开张 | `卖出`：先收 4 枚鸡蛋，走到集市换 12 金币 |
| 38 · 买种子 | `买种子`：花 3 金币买 2 颗种子，再走回起点翻土播种 |
| 39 · 买稻草 | `买稻草`：牛今天没奶、稻草也用光了，去集市买 1 捆回来喂牛、等一天、挤奶 |
| 40 · 集市毕业 | `稻草足够` 条件：稻草够就直接喂，不够就先跑一趟集市 |

第 40 关是这一章的综合题：仓库里只剩 1 捆稻草，鸡舍旁 3 只鸡等着吃。
孩子要先用「如果 稻草足够 { 喂鸡 } 否则 { 买稻草 }」判断该走哪条路，
再跑一趟集市把稻草备齐，最后喂饱、等一天、收鸡蛋。

### 玩法例子：0 金币开局，靠集市把农场转起来

自由农场开局身上一个金币都没有，只有 6 颗种子，3 只鸡和 3 头奶牛都饿着。
这时候不用急着种地——旁边那头牛今天有奶，先拿它换点本钱：

```text
// ① 先挤一瓶奶，换点本钱
右转
前进 3
挤奶
前进 2
左转
前进 1
卖出

// ② 用金币买稻草，喂饱这头牛
买稻草
左转
前进 1
喂牛

// ③ 等一天，牛又有奶了，再挤一瓶
等待一天
挤奶
```

跑完这一轮，账本是这样变的：

| 家底 | 开局 | 跑完 |
| --- | --- | --- |
| 金币 | 0 | **1** |
| 稻草 | 0 | 0（买来那捆喂牛了） |
| 牛奶 | 0 | **1** |
| 天数 | 第 1 天 | 第 2 天 |

农场每做一步都会回一句话，孩子不用记规则也能看懂刚才发生了什么：

```text
挤了 1 瓶牛奶，装进奶罐里
卖掉 1 瓶牛奶，收到 5 金币
花 4 金币买了 1 捆稻草
喂饱了 1 头牛。等一天后就能挤奶了
到了第 2 天
挤了 1 瓶牛奶，装进奶罐里
```

这一轮把三件事串成了一条线：**收成能在集市换成金币**（1 瓶牛奶 5 金币）、
**金币又能买回稻草**（4 金币 1 捆）、**喂饱的牛第二天才有奶**。
最后手里那瓶奶还没卖——想卖，走到集市旁边再写一行「卖出」就是了。

### 自由市场：没有过关目标，只有每天的账

自由模式**不用通关就能进**，一开局就有一片现成的农场和一座集市。

- **每日农活清单**：任务卡按农场现状说话——鸡舍有蛋先收蛋，牛有奶先挤奶，
  动物饿了且稻草够就提醒去喂，稻草不够就提醒先收小麦或去集市买。
- **经营账本**：每跑完一轮报一次当日结算，例如

  > 这一轮收获 4 株小麦、收到 3 枚鸡蛋、挤了 1 瓶牛奶。账本：🌾 4 小麦 · 🥚 3 鸡蛋 · 🥛 1 牛奶 · 🪙 20 金币

- **顶栏随时看家底**：金币、小麦、稻草、鸡蛋、鸡舍里攒着的蛋、饿着的鸡牛各有几只，还有第几天。
- **能扩大规模**：攒够金币可以「买鸡」「买牛」，新动物会自己找鸡舍或同伴旁边的空地。
  这两条指令**只在自由农场出现**——44 关课程里用不到，就不摆进教学模式的指令口袋，免得冒出没教过的指令。
- **进度一直存着**：农田、资源、天数、动物饱足状态都会保存，每次点运行都是接着上次的农场继续干活。

同一个经营闭环，在自由农场里就是每天照着排：

```text
收获        →  小麦 +5 金币 +2 种子 +1 稻草
喂鸡 / 喂牛  →  1 只鸡、1 头牛一天各吃 1 捆稻草
等待一天    →  浇过水的幼苗长大、鸡下蛋、牛产奶
收鸡蛋 / 挤奶 →  鸡蛋留在鸡舍，得走过去收；一头牛一天就 1 瓶奶
卖出        →  走到集市，把背包里的收成一次换成金币
买种子 / 买稻草 →  金币投回去，农场接着转
```

3 只鸡加 3 头牛一天要吃掉 6 捆稻草，所以多种几格小麦才够用；
稻草不够时就去集市买，前提是口袋里有金币。


## 玩法

开篇三步走：

1. **开篇页**：认识这片会听懂中文代码的农田，点「开始旅程」。
2. **创建小农夫**：选男孩或女孩，写下人物姓名（最多 8 个字）。
3. **选择模式**：选 **教学模式** 或 **自由模式**，正式开始。

进入游戏后：

1. 每进一个新章节，穗穗先上一节 **「穗穗小课堂」**，一句话讲清这一章要学什么，再放你进去写代码。
2. 教学模式左边是 **中文代码框**，可以在里面手写代码，也可以点击下面的「指令口袋」把指令插进去；每个按钮都写着一句「它会做什么」。
3. 点 **▶ 运行**，小农夫会一行一行执行；正在执行的那一行会亮起来。第一次玩时，第 1 关的「▶ 运行」会自己闪一闪。
4. 完成右边任务卡上的目标就算过关，按行动次数评三星。写错了不会炸：出错那行标红，**提示自动摊开**，穗穗还会补一句「下一步做什么」。
5. 真的卡住了才需要看答案：先自己试两次解锁按钮，点下去还会再确认一次。

姓名和性别都存在本地：顶栏会显示「👦 姓名」或「👧 姓名」，点右上角「模式」回到选择页，
再点「修改角色和姓名」就能随时改。

## 中文代码语法

一行一条指令，分号可有可无，`//` 或 `#` 后面是注释。

```text
前进 3          // 往前走 3 格
后退 2          // 不倒车退 2 格
左转 / 右转      // 换个方向
翻土            // 把脚下的草地翻成松土
播种            // 在松土上撒种子
浇水            // 给脚下幼苗浇水
等待一天        // 浇过水的幼苗过一晚就长大了
收获            // 收下成熟小麦，+5 金币 +2 种子
喂鸡            // 在鸡舍旁用稻草喂饱鸡群（1 只鸡 1 天 1 捆）
喂牛            // 在奶牛旁用稻草喂饱奶牛（1 头牛 1 天 1 捆）
卖出            // 在集市旁把鸡蛋、牛奶、小麦换成金币
买种子          // 在集市旁花 3 金币买 2 颗种子
买稻草          // 在集市旁花 4 金币买 1 捆稻草
买鸡 / 买牛      // 自由农场专用：在集市旁花 12 / 20 金币扩大养殖规模
收鸡蛋          // 把鸡舍里的鸡蛋收进背包
挤奶            // 在奶牛旁挤 1 瓶牛奶（一头牛 1 天 1 瓶）

重复 3 次 {
  前进
  翻土
}

如果 脚下是草地 {
  翻土
}

如果 奶牛可以挤奶 {
  挤奶
}

如果 脚下是成熟小麦 {
  收获
}
否则 {
  翻土
}

如果 稻草足够 {
  喂鸡
}
否则 {
  买稻草
}

重复 3 次 {           // 次数事先数好
  前进
}

重复直到 前方是成熟小麦 {   // 次数交给条件决定
  前进
}
```

判断条件一共九种：`脚下是草地`、`脚下是泥土`、`脚下有幼苗`、`脚下是成熟小麦`、
`奶牛可以挤奶`、`鸡舍里有鸡蛋`、`稻草足够`、`前方是成熟小麦`、`到旗子了`。

`如果` 和 `重复直到` 共用这套条件。前者是「成不成立都只做一次」，后者是
「不成立就一直做」。`重复直到` 单条最多跑 100 遍，条件写反了会被人话提示拦住，
不会把浏览器转死。

### 农场是怎么转起来的

种地、养鸡、牧牛共用一条产出链，教学关和自由模式都按这套规则结算：

```text
翻土 → 播种 → 浇水 → 等待一天 → 收获
                            ↓
                    小麦 +2 种子 +5 金币 +1 稻草
                            ↓
        ┌───────────────────┴───────────────────┐
        ↓                                       ↓
   走到鸡舍旁「喂鸡」                    走到奶牛旁「喂牛」
    （1 只鸡 1 天 1 捆稻草）             （1 头牛 1 天 1 捆稻草）
        ↓                                       ↓
   「等待一天」→ 鸡舍里攒下鸡蛋         「等待一天」→ 奶牛产奶
        ↓                                       ↓
   走到鸡舍旁「收鸡蛋」                  走到奶牛旁「挤奶」
```

**集市**把最后一环补上了：收成可以换钱，钱可以再买种子和稻草，农场能一直转下去。
价目表和买卖规则见上面的「🏪 自由市场」一节。

三条养殖规则的小细节：

- 稻草是**鸡和牛共同的口粮**：收获 1 株小麦得 1 捆稻草，喂鸡还是喂牛要自己安排。
- 鸡要**先喂饱**才下蛋，鸡蛋会**留在鸡舍里**，人走过去写「收鸡蛋」才进背包。
- 奶牛**喂饱后第二天才有新奶**，一头牛 1 天 1 瓶，挤完当天就没奶了。
- 判断条件 `奶牛可以挤奶`、`鸡舍里有鸡蛋` 可以直接用在「如果」里，让代码自己挑活干。

### 自由模式

自由模式不需要通关，启动时就能直接选择，农田、资源、天数、动物饱食和牛奶状态都会持续保存。
它的每日农活清单、经营账本、买鸡买牛和稻草开销，详见上面的「🏪 自由市场」一节。

两个和教学模式不一样的地方：

- **每次运行都接在现有农场上**，不像教学关那样每关从干净的地图重开。
- **买鸡 / 买牛**只在这里出现，课程里用不到，就不摆进教学模式的指令口袋，
  免得冒出没教过的指令。

## 关卡设计

课程分 **8 章 44 关**，每一章引入一个新概念，一关只加一个新台阶：

| 章节 | 关卡 | 这一章学什么 |
| --- | --- | --- |
| 第 1 章 · 顺序 | 1~10 | 前进 N、转向、后退 N、翻土、播种、浇水、等待、收获 |
| 第 2 章 · 重复 | 11~16 | `重复 N 次 { ... }`，把重复劳动收起来 |
| 第 3 章 · 判断 | 17~22 | `如果 脚下是... { ... }`，先看再决定 |
| 第 4 章 · 牧场 | 23~28 | `喂鸡`、`收鸡蛋`、`挤奶`、`喂牛`，把收下来的稻草变成鸡蛋和牛奶 |
| 第 5 章 · 综合 | 29~32 | 循环里套判断，用 `如果 奶牛可以挤奶` 挑活干，完成种地 + 养鸡 + 牧牛的一天 |
| 第 6 章 · 经营 | 33~36 | `如果 ... 否则 ...` 两选一，把种地、养鸡、牧牛安排成一整天的经营 |
| 第 7 章 · 集市 | 37~40 | `卖出`、`买种子`、`买稻草`、`稻草足够`，把农产品换成金币再投回农场 |
| 第 8 章 · 自动农活 | 41~44 | `重复直到`、`前方是成熟小麦`、`到旗子了`，不知道做几遍就让条件决定 |

几条不打折扣的规矩：

- **一关只教一个新东西**，新指令不会提前出现在初始代码里。
- **章节之间有小课堂**：换章先讲概念（顺序 / 重复 / 判断 / 牧场 / 综合 / 经营 / 集市 / 自动农活），再进关卡。
- **「买鸡 / 买牛」只在自由农场出现**：44 关课程用不到它们，指令口袋里也不摆，避免出现没教过的指令。
- **初始代码不是答案**（第 1 关留一行做示范），孩子必须自己动手写。
- **本章没教的语法会被"教学拦截"**，给的是提示而不是报错；前三章偷用「喂鸡 / 喂牛 / 收鸡蛋 / 挤奶」会被拦住引导到第 4 章，前五章偷用「否则」引导到第 6 章，前六章偷用「卖出 / 买种子 / 买稻草」引导到第 7 章，
前七章偷用「重复直到」引导到第 8 章。
- **每关的参考解都会被自动测试跑一遍**，保证关卡一定过得去，并且参考解能拿三星。

想加新关卡，只要在 `src/core/levels.js` 里加一条数据，然后跑 `npm test` —— 测试会替你验证地图合法、参考解能通关、一关没有塞两个新概念。

## 音频

**背景音乐**：全流程统一一首轻快的尤克里里（Happy Coconuts），从第 1 关到自由模式
都不换曲，避免孩子被换歌分心；另叠一层很轻的鸟鸣环境音，
点运行时代码音乐会自动压低，不盖住音效。

**音效**：走路踩草、翻土、播种、浇水、发芽、收获、金币、鸡叫、牛叫、挤奶、
公鸡打鸣、按钮、走不通、代码报错、过关小号和通关庆祝，全部接在对应事件上。

**丰收仙女语音**：农田提示位新增女性精灵教师「牧场丰收仙女 · 穗穗」。
点“提示”时，屏幕会展开本关提示，她用坎蒂丝音色朗读该关第一条精确指导；
写错代码或看答案时也会给出语音引导。语音使用本机原神 TTS 预生成，
运行游戏不联网。关卡提示有改动后运行：

```bash
node tools/generate_tutor_voice.mjs --force   # 只补缺失的可去掉 --force
```

脚本会用 `src/assets/voice/voice-manifest.json` 记录每句台词的指纹，只补「台词改了或
文件缺失」的那些；`npm test` 会校验提示文本和配音是否同步，防止录音和屏幕上写的对不上。
只想补个别关卡时可以写 `--only=level-26,level-27`。

脚本默认读本机的 TTS 目录与 Python 环境，换机器时用环境变量覆盖：

```bash
TTS_PYTHON=/path/to/venv/bin/python TTS_SERVER=/path/to/tts_server.py \
  node tools/generate_tutor_voice.mjs
```

生成的语音已经提交进仓库（`src/assets/voice/`），普通玩家不用跑这一步。

素材**不复制进项目**，直接读本机统一素材库（和有声小说项目共用）：

```
/media/sfx/*    →  ~/Documents/ChatGPT/语音合成/音效库
/media/music/*  →  ~/Documents/ChatGPT/语音合成/音乐库
```

素材取不到时（比如玩 Release 里的单文件版、或者在没装素材库的机器上跑），
游戏会自动退回 WebAudio 合成音，照样有反馈，不会报错也不会静音。

## 目录结构

```
src/
├── core/                 纯逻辑，不碰任何画面
│   ├── interpreter.js    中文代码：词法 → 语法 → 逐行执行
│   ├── tutor.js          教学拦截：本章没教的语法给提示而不是报错
│   ├── world.js          农场规则：移动、翻土、生长、收获、养殖、集市买卖
│   ├── levels.js         44 关关卡数据
│   ├── runner.js         把解释器和世界接起来，每步检查目标
│   ├── engine.js         事件 → 补间动画 / 特效 / 音效
│   ├── render.js         Canvas2D 像素画笔
│   ├── audio.js          真实录音 + 合成音兜底
│   ├── tutor-lines.js    丰收仙女台词与配音清单
│   └── credits.js        素材致谢
├── ui/
│   ├── app.js            面板装配、存档、关卡切换
│   ├── editor.js         中文代码编辑器（行号 / 高亮 / 报错行）
│   └── styles.css        木牌像素风界面
└── game.js               入口

tools/dev-server.mjs      零依赖静态服务器 + 素材库映射
tools/generate_tutor_voice.mjs  用坎蒂丝音色批量生成仙女提示语音
tools/build-single.mjs    打包成单文件 HTML（产物在 dist/）
tools/capture-preview.mjs 用无头 Chrome 重拍 README 里的预览图
tests/levels.test.mjs     关卡与解释器自检
```

玩法逻辑（`core/`）完全不知道"画面"的存在，所以关卡能脱离浏览器在 Node 里跑测试；
换美术、换音效、换界面都不会碰到规则本身。
